# Design Sources

The package treats Basalt Core and Basalt Warehouse as the primary local contracts. Framework source URLs are preserved from the configured control catalogue and surfaced in citations.

| Source | Role in Basalt RAG |
|---|---|
| [Basalt Core control catalogue](https://github.com/kingsokafor777-droid/basalt-core) | Qualified control IDs, titles, family metadata, source URL, and authority flag. |
| [Basalt Warehouse data contract](https://github.com/kingsokafor777-droid/basalt-warehouse) | Immutable finding evidence and current-findings retrieval grain. |
| [NIST SP 800-53 Rev. 5](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final) | Framework publication linked by the shipped NIST seed catalogue. |
| [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks) | Framework publication family linked by the shipped CIS seed catalogues. |
